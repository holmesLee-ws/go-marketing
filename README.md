# go-marketing

마케팅 전략, 퍼포먼스·그로스, 브랜드, 가격, 그리고 국내 마케팅 법규를 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 한국 법·제도를 뼈대로 EU·미국 기준을 비교합니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료, 이미지를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

> 튜터의 법규 설명은 학습용입니다. 법률 자문이 아니므로 실제 집행 전에는 법무·전문가 확인을 받으세요.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 공개 리포라 초대 없이 받을 수 있습니다. 터미널에서 `gh auth login`으로 한 번 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-marketing
```

**Claude Code**

```bash
cd ~/Desktop/go-marketing
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-marketing` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 무엇을 팔거나 맡고 있는지, 실무 경험은 어떤지 짧게 묻고, 영역마다 상황 문제를 하나씩 풀어 출발점을 찾습니다. 마케팅이 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 내 제품·업무 장면으로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다. 법이 걸리는 장면에서는 튜터가 국가법령정보센터 같은 공식 출처를 그 자리에서 확인하고 출처와 조회일을 남깁니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.
6. 마지막에는 실제 업무에 쓸 시장 진입 계획서와 마케팅 컴플라이언스 체크리스트 초안을 만듭니다.

내 광고 문구, 상세페이지, 문자 메시지, 가격표를 가져오면 그걸로 연습합니다. 고객 이름·연락처 같은 개인정보는 지우고 가져오세요.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도(M 전략 · G 그로스 · B 브랜드 · P 가격과 유통 · L 법규 실무 · X 졸업) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 업무 문서 초안. 처음 시작할 때 생깁니다 |
| [docs/build/](docs/build/) | 이 리포를 만든 기록과 법령 출처(학습에는 필요 없음) |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

B2B 영업(리드·제안·클로징), 개인정보 보안, 재무·회계 해석처럼 다른 영역은 go-sales, go-security, go-finance 같은 별도 워크스페이스가 다룹니다. 여기서는 연결만 짚습니다.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/projects`의 문서 초안을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 민감한 정보는 대화에 넣지 마세요.
